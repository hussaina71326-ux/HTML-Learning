📚 Topics Covered
1. HTML Document Structure
Basic HTML structure:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Day 15</title>
</head>
<body>

    <h1>Hello World</h1>

</body>
</html>
2. Headings
HTML provides six heading levels:

<h1>Main Heading</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>
<h1> is the highest-level heading and <h6> is the lowest.

3. Paragraph
The <p> element is used to write paragraphs.

<p>This is a paragraph.</p>
4. Links
The <a> element creates hyperlinks.

<a href="https://www.google.com">Visit Google</a>
Important attribute:

href → specifies the destination URL.

5. Images
The <img> element displays an image.

<img src="image.jpg" alt="Example Image">
Important attributes:

src → image location

alt → alternative text

6. Lists
Unordered List
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
Ordered List
<ol>
    <li>Learn HTML</li>
    <li>Learn CSS</li>
    <li>Learn JavaScript</li>
</ol>
7. Text Formatting
Common formatting elements:

<b>Bold Text</b>
<strong>Important Text</strong>
<i>Italic Text</i>
<em>Emphasized Text</em>
<u>Underlined Text</u>
<mark>Highlighted Text</mark>
<small>Small Text</small>
8. Tables
Basic table structure:

<table border="1">
    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>

    <tr>
        <td>Ahmed</td>
        <td>20</td>
    </tr>
</table>
Important elements:

<table> → creates a table

<tr> → table row

<th> → table heading

<td> → table data

9. Forms
Basic form example:

<form>
    <label for="name">Name:</label>
    <input type="text" id="name" name="name">

    <br><br>

    <label for="email">Email:</label>
    <input type="email" id="email" name="email">

    <br><br>

    <button type="submit">Submit</button>
</form>

🏗️ Semantic HTML
Semantic elements clearly describe the purpose of their content.

Common semantic elements:

<header></header>
<nav></nav>
<main></main>
<section></section>
<article></article>
<aside></aside>
<footer></footer>
Example:

<header>
    <h1>My Website</h1>
</header>

<nav>
    <a href="#">Home</a>
    <a href="#">About</a>
</nav>

<main>
    <section>
        <h2>About Me</h2>
        <p>Welcome to my website.</p>
    </section>
</main>

<footer>
    <p>Copyright © 2026</p>
</footer>
🏷️ Important HTML Attributes
Some commonly used attributes are:

Attribute	Purpose
id	Gives a unique identity to an element
class	Groups elements for styling/scripts
href	Specifies a link destination
src	Specifies a resource location
alt	Alternative text for images
title	Provides additional information
name	Identifies form data
value	Specifies an input value
placeholder	Displays hint text in an input
target	Controls where a link opens
